# Clubtone TOP Player Fix 1.5.24

Скрипт для браузера Chrome, который восстанавливает работу штатного плеера Clubtone, обеспечивая воспроизведение музыки через Soundfiles

## Установка

### 1. Установить [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=ru)

Открыть страницу расширения по ссылке выше, нажать «Установить» и подтвердить добавление в браузер

### 2. Разрешить пользовательские скрипты					 				

Нажать правой кнопкой мыши на значок Tampermonkey → «Управление расширением» → включить **«Разрешить пользовательские скрипты»**

Если этого переключателя нет то следуйте [инструкции Tampermonkey](https://www.tampermonkey.net/faq.php?q=Q209) → открыть меню Chrome (три точки в правом верхнем углу) → «Расширения» → «Управление расширениями» (или ввести `chrome://extensions/` в адресной строке) и включить **«Режим разработчика»** в правом верхнем углу

### 3. Установить скрипт

**Основной способ:** 

1. Открыть [Clubtone TOP Player Fix](https://raw.githubusercontent.com/Emparda/clubtone-top-player-fix/refs/heads/main/clubtone-player-fix.user.js) и нажать «Установить» в Tampermonkey. При успешной установки достаточно только этого способа. Несколько включённых копий одного скрипта могут мешать друг другу

**Импорт файла:**

1. Скачать файл [clubtone-player-fix.user.js](https://github.com/Emparda/clubtone-top-player-fix/blob/main/clubtone-player-fix.user.js)
2. Открыть Tampermonkey → «Панель управления» → «Утилиты» → «Импорт файлов»
3. Выбрать скачанный файл и подтвердить установку

**Вставка кода из TXT:**

1. Скачать и открыть [clubtone-player-fix.txt](https://github.com/Emparda/clubtone-top-player-fix/blob/main/clubtone-player-fix.txt)
2. Выделить весь текст (`Ctrl+A`) и скопируйте его (`Ctrl+C`)
3. В Tampermonkey нажать «Создать новый скрипт» (кнопка «+»)
4. Полностью удалить шаблон кода и вставить скопированный код (`Ctrl+V`)
5. Сохранить скрипт (`Ctrl+S`)

### 4. Откройте Clubtone

Перейти на [clubtone.do.am](https://clubtone.do.am/) или [clubtone.net](https://clubtone.net/). Скрипт запускается автоматически. Сохраняются привычный вид плеера и основные способы управления

## Если скрипт не работает

- Проверить разрешение на пользовательские скрипты в Chrome (шаг 2 установки)
- Обновить страницу Clubtone нажав **Ctrl+F5**
- Обновить страницу Tampermonkey с расширением нажав **Ctrl+F5**
- Перезапустить Chrome
- Открыть Tampermonkey и убедиться, что скрипт Clubtone TOP Player Fix включён
- Выключить и снова включить скрипт в Tampermonkey, затем обновить Clubtone
- Проверить, не блокирует ли блокировщик рекламы запросы Clubtone или Soundfiles. Для проверки можно временно отключить его именно на этих сайтах
- Если спустя некоторое время после успешной установки скрипта воспроизведение треков перестало работать, нажмите кнопку загрузки любого трека, чтобы открыть Soundfiles. Сервис может временно ограничивать доступ по IP-адресу через систему защиты BitNinja. Пройдите проверку на открывшейся странице, после чего вернитесь на Clubtone - воспроизведение восстановится. Если трек не играет и на самом Soundfiles, причина может быть в недоступности файла или сервиса. Скрипт не может восстановить удалённое аудио и не обходит проверку Soundfiles

## Изменения и возможности

- Воспроизведение и загрузка треков напрямую через **Soundfiles** вместо Zippyshare
- Восстановлена работа штатного плеера во всех разделах Clubtone
- Исправлена ошибка отображения страницы после перехода на треки из раздела - Последние комментарии
- При поиске музыки с главной страницы исправлено отображение треков
- Изменено управление плеером по горячим клавишам текущего трека на отдельной странице 
- Предзагрузка трёх следующих треков в разделах ТОП 100 - переключение между подготовленными потоками практически мгновенное
- Сохранение истории прослушивания, общей для обоих доменов clubtone.do.am и clubtone.net. Названия прослушанных треков отмечаются не только штатным (серым цветом) CSS-состоянием :visited от бразуера Chrome, но теперь и отдельной логикой скрипта. Это значит, что история ID прослушанных треков (без аудио, обложек и т. п.) сохраняется локально в хранилище Tampermonkey. Она не сбрасывается при обновлении страницы, перезапуске браузера или включении и выключении скрипта. При удалении скрипта вместе с его данными история прослушивания будет потеряна, но останутся отметки посещений, сохранённые самим браузером

## Управление плеером

### В ТОПах и списках разделов

- **W** - Открыть страницу текущего трека на используемом зеркале
- **A** - Предыдущий трек
- **S** - Воспроизведение / пауза
- **D** - Следующий трек
- **F** - Открыть страницу скачивания на Soundfiles

### На отдельной странице трека

- **W** - Начать воспроизведение заново с начала трека
- **A** - Перемотать на 5 секунд назад
- **S** - Воспроизведение / пауза
- **D** - Перемотать на 5 секунд вперёд
- **F** - Открыть страницу скачивания на Soundfiles

## Обновление

При включённой проверке обновлений Tampermonkey периодически проверяет новые версии. Проверка не обязательно происходит сразу после публикации. **Установить обновление** можно по [ссылке](https://raw.githubusercontent.com/Emparda/clubtone-top-player-fix/refs/heads/main/clubtone-player-fix.user.js) или вручную в настройках скрипта → Настройки → Обновления → Проверить обновления скриптов
