# Clubtone TOP Player Fix 1.5.24

Восстанавливает работу штатного плеера Clubtone в поддерживаемых ТОП-списках и на страницах отдельных треков, обеспечивая воспроизведение музыки через Soundfiles

Автор: **Dmitriy Oshev**. Создан с помощью **Codex GPT**.  
Дата создания скрипта: **2 октября 2026 года**.

## Установка и обновление

[Установите Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=ru), затем [откройте скрипт](https://raw.githubusercontent.com/Emparda/clubtone-top-player-fix/refs/heads/main/clubtone-player-fix.user.js) и подтвердите установку/обновление. Эта ссылка начнёт выдавать актуальную версию скрипта после публикации файлов владельцем репозитория.

### 1. Установите Tampermonkey в Chrome

Откройте страницу расширения по ссылке выше, нажмите «Установить» и подтвердите добавление в браузер.

### 2. Разрешите пользовательские скрипты

Нажмите правой кнопкой на значок Tampermonkey → «Управление расширением» → включите **«Разрешить пользовательские скрипты»**.

Если этого переключателя нет, откройте меню Chrome → «Расширения» → «Управление расширениями» (или введите `chrome://extensions/` в адресной строке) и включите **«Режим разработчика»** в правом верхнем углу.

Без разрешения Chrome может блокировать запуск скрипта. В актуальном Chrome это альтернативные способы: включать оба переключателя обязательно не требуется. [Официальная инструкция Tampermonkey](https://www.tampermonkey.net/faq.php?q=Q209).

### 3. Установите скрипт

**Основной способ:** [открыть Clubtone TOP Player Fix](https://raw.githubusercontent.com/Emparda/clubtone-top-player-fix/refs/heads/main/clubtone-player-fix.user.js) и нажать «Установить» в Tampermonkey.

**Альтернатива — импорт файла:**

1. Скачайте файл `clubtone-player-fix.user.js` из репозитория.
2. Откройте Tampermonkey → «Панель управления» → «Утилиты» → «Импорт файлов».
3. Выберите скачанный файл и подтвердите установку.

**Альтернатива — вставка кода из TXT:**

1. Скачайте и откройте `clubtone-player-fix.txt`.
2. Выделите весь текст (`Ctrl+A`) и скопируйте его (`Ctrl+C`).
3. В Tampermonkey нажмите «Создать новый скрипт» (кнопка «+»).
4. Полностью удалите шаблон и вставьте скопированный код (`Ctrl+V`).
5. Сохраните скрипт (`Ctrl+S`).

Выберите один способ установки. Несколько включённых копий одного скрипта могут мешать друг другу.

При включённой проверке обновлений Tampermonkey периодически проверяет новые версии по адресам, указанным внутри скрипта. Проверка не обязательно происходит сразу после публикации. Установить опубликованное обновление вручную можно по основной ссылке выше.

### 4. Откройте Clubtone

Перейдите на [clubtone.do.am](https://clubtone.do.am/) или [clubtone.net](https://clubtone.net/). Скрипт запускается автоматически. Сохраняются привычный вид нижнего плеера и основные способы управления.

## Управление плеером

### В ТОПах и списках разделов

| Клавиша | Действие |
| --- | --- |
| **W** | Открыть страницу текущего трека на используемом зеркале |
| **A** | Предыдущий трек |
| **S** | Воспроизведение / пауза |
| **D** | Следующий трек |
| **F** | Открыть страницу скачивания на Soundfiles |

### На отдельной странице трека

| Клавиша | Действие |
| --- | --- |
| **W** | Начать воспроизведение заново с начала трека |
| **A** | Перемотать на 5 секунд назад |
| **S** | Воспроизведение / пауза |
| **D** | Перемотать на 5 секунд вперёд |
| **F** | Открыть страницу скачивания на Soundfiles |

Удерживайте **A** или **D**, чтобы повторять перемотку до отпускания клавиши. При вводе текста в поле поиска или комментария горячие клавиши плеера не срабатывают.

## Если скрипт не работает

После каждого шага обновляйте страницу и проверяйте воспроизведение.

1. Проверьте разрешение на пользовательские скрипты в Chrome (шаг 2 установки).
2. Обновите страницу сочетанием **Ctrl+F5**.
3. Перезапустите Chrome.
4. Убедитесь, что Clubtone TOP Player Fix включён в Tampermonkey.
5. Выключите и снова включите скрипт, затем обновите страницу.
6. Проверьте, не блокирует ли блокировщик рекламы запросы Clubtone или Soundfiles. Для проверки можно временно отключить его именно на этих сайтах.
7. Если музыка работала и внезапно перестала, откройте страницу Soundfiles кнопкой скачивания или клавишей **F**. Сервис может показывать проверку BitNinja для вашего IP-адреса. Пройдите её самостоятельно, вернитесь в Clubtone и повторите запуск. При сообщении плеера об ошибке используйте кнопку **«Повторить»**.

Если трек не играет и на самом Soundfiles, причина может быть в недоступности файла или сервиса. Скрипт не может восстановить удалённое аудио и не обходит проверку Soundfiles. Закрытые разделы Clubtone требуют входа в аккаунт сайта.

## Изменения и возможности

- Воспроизведение и скачивание через **Soundfiles** вместо неработающих ссылок старого плеера на Zippyshare.
- Поддержка штатного нижнего плеера в ТОП-списках, на отдельных страницах треков, в списках «Клубная музыка», Lossless, «Запрещённые материалы» и подразделах по стилям с соответствующей разметкой сайта.
- Воспроизведение возможно, если у трека есть доступная ссылка Soundfiles. Старые материалы только с удалёнными ссылками не восстанавливаются автоматически.
- Исправление повреждённых ссылок из «Последних комментариев» и приведение ссылок треков к текущему зеркалу.
- Исправление ложного состояния «трек удалён» в поиске и списках, восстановление доступных обложек. Если обложка действительно отсутствует, остаётся штатная заглушка.
- Сохранение управления громкостью, перемоткой, скачиванием и отображения звуковой волны трека.
- Разные назначения горячих клавиш для списков и отдельной страницы трека.
- Предзагрузка **трёх следующих аудиопотоков**: подготовленные треки переключаются практически мгновенно. Скорость зависит от сети и доступности Soundfiles.
- Общая история прослушанных треков и открытых страниц для **clubtone.do.am** и **clubtone.net**, с отметками ссылок по всему сайту.

## История прослушивания

Прослушанные треки и открытые страницы отмечаются привычным серым цветом. Работают и браузерная история посещений, и общая история скрипта для двух зеркал.

Скрипт сохраняет только идентификаторы треков в хранилище **Tampermonkey в вашем браузере**, без аудио и обложек. Сам скрипт не отправляет эту историю на сервер. Она сохраняется после обновления страницы, перезапуска браузера и выключения или включения скрипта.

**При удалении скрипта вместе с его данными история скрипта будет потеряна.** Его отметки исчезнут, но ссылки, которые Chrome по-прежнему считает посещёнными, могут остаться серыми благодаря браузерной истории.
