# Clubtone TOP Player Fix 1.5.35

Скрипт для Chrome и Firefox, который восстанавливает работу штатного плеера Clubtone, обеспечивая воспроизведение музыки через Soundfiles

## Установка в браузере Chrome

### 1. Установить [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=ru)

- Открыть страницу расширения по ссылке выше, нажать «Установить» и подтвердить добавление в браузер

### 2. Разрешить пользовательские скрипты					 				

- [Инструкция Tampermonkey](https://www.tampermonkey.net/faq.php?q=Q209) → Нажать правой кнопкой мыши на значок Tampermonkey → «Управление расширениями» → включить **«Разрешить пользовательские скрипты»**


- Если этого переключателя нет то выполнить следующие действия:   
→ открыть меню Chrome, нажав три точки в правом верхнем углу → «Расширения»   
→ «Управление расширениями» или ввести `chrome://extensions/` в адресной строке  
→ включить **«Режим разработчика»** в правом верхнем углу

### 3. Установить скрипт

**Основной способ:** 

- Открыть [Clubtone TOP Player Fix](https://raw.githubusercontent.com/Emparda/clubtone-top-player-fix/refs/heads/main/clubtone-player-fix.user.js) и нажать «Установить» в Tampermonkey
- При успешной установке достаточно только этого способа

**Импорт файла:**

- Скачать файл [clubtone-player-fix.user.js](https://github.com/Emparda/clubtone-top-player-fix/blob/main/clubtone-player-fix.user.js)
- Открыть Tampermonkey → «Панель управления» → «Утилиты» → «Импорт файлов»
- Выбрать скачанный файл и подтвердить установку

### 4. Открыть Clubtone

- Готово, можно перейти на [clubtone.do.am](https://clubtone.do.am/) или [clubtone.net](https://clubtone.net/). Скрипт запускается автоматически   
Сохраняются привычный вид плеера и основные способы управления

## Установка в браузере Firefox

## Если скрипт не работает

- **Стабильная работа предусмотрена везде, где есть актуальные ссылки на Soundfiles**  
В иных случаях работа не гарантируется из-за нерабочих или устаревших ссылок на другие ресурсы для воспроизведения и загрузки треков
- Проверить разрешение на пользовательские скрипты в Chrome (шаг 2 установки)
- Обновить страницу Clubtone, нажав **Ctrl+F5**
- Открыть Tampermonkey и убедиться, что скрипт Clubtone TOP Player Fix включён
- Обновить страницу с расширением Clubtone TOP Player Fix в Tampermonkey, нажав **Ctrl+F5**
- Выключить и снова включить скрипт в Tampermonkey, затем обновить Clubtone
- Проверить, не блокирует ли блокировщик рекламы запросы Clubtone или Soundfiles. Для проверки можно временно отключить его именно на этих сайтах
- Если спустя некоторое время после успешной установки скрипта воспроизведение треков перестало работать, нажать кнопку загрузки любого трека, чтобы открыть Soundfiles. Сервис может временно ограничивать доступ по IP-адресу через систему защиты BitNinja. Пройти проверку на открывшейся странице, после чего вернуться на Clubtone - воспроизведение восстановится. Если трек не играет и на самом Soundfiles, причина может быть в недоступности файла или сервиса. Скрипт не может восстановить удалённое аудио и обойти проверку Soundfiles
- Иногда помогает простой перезапуск Chrome если произошёл сбой воспроизведения плеера из-за неизвестных ошибок в связке Chrome и Tampermonkey

## Изменения и возможности

- Воспроизведение и загрузка треков напрямую через **Soundfiles** вместо Zippyshare
- Восстановление работы штатного плеера во всех разделах Clubtone
- Один активный плеер: запуск музыки в другой вкладке ставит предыдущую на паузу, сохраняя позицию
- Изменение управлением воспроизведения с помощью горячих клавиш на страницах отдельных треков
- Уведомления: ошибки источника, кнопки перехода и повторной попытки
- Исправлена ошибка 404 при открытии страниц треков из раздела «Последние комментарии»
- Переходы между треками сохраняют используемое зеркало (домен)
- Настройка правильной работы поисковика во всех разделах Clubtone
- Мелкие правки в оформлении и конфигурации
- Предзагрузка трёх следующих треков для быстрого переключения в ТОП 100, Клубная музыка и т.д.
- Общая история прослушивания для обоих доменов clubtone.do.am и clubtone.net. Названия прослушанных треков отмечаются не только штатным (серым цветом) CSS-состоянием :visited от браузера Chrome, но теперь и отдельной логикой скрипта. Это значит, что параллельно Chrome, история ID прослушанных треков (без аудио, обложек и т. п.) сохраняется локально в хранилище Tampermonkey. Она не сбрасывается при обновлении страницы, перезапуске браузера или включении и выключении скрипта. При удалении скрипта вместе с его данными история прослушивания будет потеряна, но останутся отметки посещений, сохранённые самим браузером

## Управление плеером

### В ТОПах и списках разделов

- **W** - Открыть страницу текущего трека
- **A** - Предыдущий трек
- **S** - Воспроизведение / пауза
- **D** - Следующий трек
- **F** - Открыть страницу скачивания на Soundfiles

### На отдельной странице трека

- **W** - Начать воспроизведение заново с начала трека
- **A** - Перемотать на 5 секунд назад
- **S** - Воспроизведение / пауза
- **D** - Перемотать на 5 секунд вперёд
- **F** - Открыть страницу скачивания на Soundfiles

## Обновление

- При включённой проверке обновлений Tampermonkey периодически проверяет новые версии, но проверка не обязательно происходит сразу после публикации
- Доступное обновление (новую версию) можно установить самому, выбрав нужную ссылку на [Chrome](https://raw.githubusercontent.com/Emparda/clubtone-top-player-fix/refs/heads/main/clubtone-player-fix.user.js) или [Firefox](https://raw.githubusercontent.com/Emparda/clubtone-top-player-fix/refs/heads/main/clubtone-player-fix-firefox.user.js)
- Установить обновление вручную или включить проверку обновлений → Панель управления Tampermonkey → Нажать на Clubtone TOP Player Fix → Настройки → Обновления
